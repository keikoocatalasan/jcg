## Defects Found and Fixed

1. Forced session/onboarding bypasses exposed authenticated content.
2. Conflicting Supabase/FastAPI configuration was centralized in `AppConfig`.
3. Registration did not expose session/email-confirmation state or preserve metadata.
4. Route guards did not react correctly across auth, onboarding, and admin states.
5. Admin role trusted mutable local SQLite data and child routes were unguarded.
6. Initial catalog pull queried incompatible tables and boolean values.
7. Meal search closed unexpectedly; quantities treated grams as serving counts.
8. Meal saves did not invalidate dashboard providers.
9. Water logs bypassed the sync queue and did not refresh the dashboard.
10. Weight saves included a hydration column and omitted `user_id`.
11. Meal/water/weight/target/snapshot payloads did not match normalized Supabase tables.
12. Active nutrition targets violated the one-active-target constraint during recalculation.
13. Session loading generated negative layout constraints during cold start.
14. Settings used an infinite-width button inside a row and rendered blank.
15. Failed sync items were incorrectly reported as “all synced.”
16. Chatbot JWT validation only supported HS256; local Supabase uses ES256/JWKS.
17. Chatbot request, response, and context field names did not match FastAPI.
18. Chat session/message and meal-plan sync lacked normalized mappings; planned-meal payloads used invalid Dart map strings.
19. Analytics recreated a new family key every build, causing an endless loading loop.
20. Scanner requested microphone access unnecessarily.
21. Scanner registered `ref.listen` from `initState`, used the wrong multipart field, and parsed obsolete response keys.
22. Admin reports used nonexistent plural tables and lacked report grants.
23. Admin price history was inaccessible and displayed hard-coded values.
24. Logout popped the router after the auth guard had already redirected, leaving a blank screen.
25. Login trusted stale local onboarding `false` before checking the completed remote profile.
