# JCG Fitness 1.0.5

This release refines the JCG Fitness experience with a premium glassmorphism
chatbot, a simpler nutrition-coach entry state, compact quick-start prompts,
and clearer user/coach message bubbles.

It also includes the Community safety and feed polish, meal-period-aware Manual
Log search, responsive phone-width meal details, the light branded landing page
updates, and the server-side Community safety migration.

Packages retain application ID `com.jcg.fitness`, the JCG Fitness label, the
existing production signing certificate, Android API 26 minimum and API 35
target. All universal and ABI packages use global Android version code `4006`.

Existing users should install the new APK over the current JCG Fitness install;
the application ID and signing certificate remain unchanged, so local data and
the authenticated account are preserved. Android still requires the user to
approve the installation.
