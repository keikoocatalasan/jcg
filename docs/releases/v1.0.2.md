# JCG Fitness 1.0.2

## Highlights

- Google Sign-In configured for the production Android certificate and Supabase
  provider.
- Existing email/password accounts can link Google without creating a duplicate
  Supabase user.
- Settings and dashboard now check for newer releases using signed release
  metadata.
- Public downloads use branded filenames and include a smaller ARM64 package,
  plus a resumable fallback for interrupted large downloads.
- The landing page has current app previews, a light layout, and public privacy
  and terms pages.

## Android downloads

- `JCG-Fitness.apk`: universal APK.
- `JCG-Fitness-arm64-v8a.apk`: smaller package for modern 64-bit Android phones.
- `JCG-Fitness-armeabi-v7a.apk`: 32-bit ARM package.
- `JCG-Fitness-x86_64.apk`: emulator/x86_64 package.
- `SHA256SUMS.txt`: checksums for branded packages.

The Android 10+ target is verified in the emulator. Android 8.0/API 26 remains
the package minimum for dependency compatibility.
