# JCG Fitness 1.0.4

This maintenance release fixes the AI Food Scanner startup lifecycle. Reopening
the scanner now resets its result state after the first frame, avoiding a
Riverpod build-time state mutation and keeping the camera/sample-image flow
responsive.

Packages retain application ID `com.jcg.fitness`, the JCG Fitness label, the
existing production signing certificate, Android API 26 minimum and API 35
target. All universal and ABI packages use global Android version code `4005`.
