# JCG Fitness 1.0.1

First public Android release of JCG Fitness.

## Included

- Budget-aware nutrition dashboard and meal recommendations
- Filipino food scanning with local pilot model and manual confirmation
- Meal, water, and weight logging with date and time editing
- Community feed and admin statistics console
- Offline-first local persistence with later synchronization
- Safety-gated nutrition chatbot integration

## Downloads

- `app-release.apk`: universal APK for Android 8.0 and newer
- `app-arm64-v8a-release.apk`: smaller APK for 64-bit ARM phones
- `app-armeabi-v7a-release.apk`: smaller APK for 32-bit ARM phones
- `app-x86_64-release.apk`: emulator and x86_64 devices
- `SHA256SUMS.txt`: SHA-256 checksums for all APKs

Install the universal APK when unsure which architecture your phone uses. The
APK is signed with the JCG Fitness release certificate. Keep the same signing
identity for future updates so Android can update the app in place.

JCG Fitness is an Android APK. iOS installation requires a separately signed
App Store or iOS distribution build.
