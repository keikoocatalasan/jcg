# JCG Fitness 1.0.3

This release fixes Android in-place updates when a user previously installed an
ABI-specific APK. Universal and ABI packages now share the same global Android
version code (`4004`), so the official universal download can update any prior
v1.0.2 package without triggering a version downgrade.

Packages:

- `JCG-Fitness.apk`: universal package for Android 8.0 and newer.
- `JCG-Fitness-arm64-v8a.apk`: smaller 64-bit ARM package.
- `JCG-Fitness-armeabi-v7a.apk`: 32-bit ARM package.
- `JCG-Fitness-x86_64.apk`: emulator/x86_64 package.

All packages use application ID `com.jcg.fitness`, display name `JCG Fitness`,
minimum Android API 26, target API 35, and the existing production signing
certificate. Online authentication, database, AI scanning and chatbot features
require an internet connection.
