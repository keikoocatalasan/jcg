Need help getting started?

The download did not start

Open this page in your Android browser rather than a messaging app's built-in viewer. Check your connection and storage, then try the release page and choose the universal APK. No GitHub account is required.

Android will not install the downloaded file

Open the APK from Downloads. Android may ask you to allow installation from your browser or file manager. If it reports a package conflict or another error, keep the exact message. Do not uninstall your existing app just to retry. Work or school devices may restrict installation.

Is the app free?

JCG Fitness is free to download. Mobile data charges may apply. Login, cloud data and AI features need internet access; online services may have delays or usage limits.

How do updates work?

Return here for the latest published release and install it over your existing JCG Fitness app to preserve your data. Android will ask you to review the update; downloading does not install it automatically.
